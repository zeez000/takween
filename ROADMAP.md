# Roadmap

## Phase 0 - Foundation

Next.js, TypeScript, Tailwind v4, Motion, configurable identity and shared components.
Project documentation, proposed database architecture and verification tooling.
Runtime results recorded separately in VERIFICATION.md.

## Phase 1 - Working homepage

Hero, about, services, process, materials, portfolio empty state, local enquiry
draft and file validation, conditional WhatsApp, Fateen and responsive footer.
Operations and tracking placeholder routes.
Confirm branding, contact, printer and launch readiness before publication.

## Phase 2 - Secure enquiry intake

Approve privacy/retention policy; configure Supabase only after approval.
Implement migrations, grants, RLS, private storage and access tests.
Admin login and server-side allowlist checks. Rate-limited intake with validation.
Quarantine uploads, content/size/format checks and isolated processing.
Admin enquiry and file-review workflows. Test customer cross-access denial.

## Phase 3 - Quotes and production

Owner-configured estimation assumptions: material, machine time, energy, labour,
waste, post-processing, packaging, overhead and margin. No invented default rates.
Manual quote versions, expiry and acceptance. Transactional order creation.
Production stages, stock reservation/consumption and verified private tracking.

## Phase 4 - Operations

Spool movement ledger, product publishing, permission-backed portfolio media,
payments/refunds, expenses and reporting. Separate estimates, actual job margin
and cash flow. Add audit trail, backups, deletion workflows and monitoring.

## Phase 5 - Expansion

Assess additional printers, plastic recycling and outsourced metal work using
actual demand and unit economics. Confirm Fateen availability separately.

## Launch gate

Build/tests and real-iPhone checks; confirmed contacts/specifications;
secure intake and administration; upload controls; privacy information;
explicit owner approval for hosting/publication. No deployment in this phase.

## Cinematic milestone completed
TAKWEEN branding, optional entry, original procedural assembly, reversible native-scroll choreography, drag/reset/zoom, fallbacks and browser regressions are implemented. See BLUEPRINT_AUDIT.md for remaining blueprint scope and VERIFICATION.md for actual results.

## Supabase approval milestone
Review docs/SUPABASE_PLAN.md. No backend implementation or migration before owner approval.
